# 0.7.0-alpha 代码审查与验证记录

日期：2026-10-02。范围为本地源码、固定版本依赖源码/字节码及非游戏测试；未启动客户端、服务端或 GameTest，未控制桌面。此记录不等于完整实机兼容性认证。

## 已检查的主要路径

| 范围 | 结果 |
| --- | --- |
| 轴承、直线运动、矿车与稳定子结构碰撞 | 核对实际方块形状、扫掠、子结构传播、预算限制与同族排除；保留现有几何语义。石墙 1.5 格碰撞箱不是误判，不做特殊放行。 |
| 旋转精检 | 半径由每次递归计算改为每次形状对计算一次；实际中点形状已重叠时立即返回，不再递归证明已经确定的碰撞。粗包围盒命中仍不能单独证明碰撞。 |
| 实时方块索引 | 红石、动画等状态变化且成员不变时返回原数组，避免重复构建装箱集合与数组；增删仍采用写时复制，不修改拆卸正在使用的快照。 |
| 库存/流体视图 | 收集能力时消除一次重复查询；不增加持久缓存，视图操作仍实时访问真实方块实体，保持唯一库存归属。 |
| 实体生命周期与缓存 | 客户端控制器缓存清理死亡、失效或更换归属的条目；弱引用只读取一次，避免二次读取间回收。检查服务端关节卸载清理与矿车载体销毁释放路径。 |
| 装配异常 | 补上晚期失败时已发布 UUID 的清理，以及强制加载票据的显式移除，再执行原有方块恢复。 |
| 状态与网络 | HUD 仍使用服务端小整数状态，不新增自定义数据包。语言由各客户端解释。客户端 HUD 开关不改变服务端碰撞/工作行为。 |
| 配置与分端 | 使用 NeoForge 21.1.228 原生 ConfigurationScreen 和 ModConfigSpec；注册界面放在 Dist.CLIENT 入口，游戏规则使用 SERVER 配置。 |
| 可选 Simulated | 保留 @Pseudo 入口保护和交互检查；不新增必装依赖。该模组 JAR 不在本地验证矩阵内。 |
| 火车 | 新功能仅通过既有 managed/supported 结构筛选；未扩展火车物理化范围。未进行普通火车实机回归。 |

## 游戏内配置

入口：Mods → Sable Physical Contraptions → 配置。

- 客户端：护目镜 HUD、停转原因显示；保存后用于后续绘制。
- 服务端：旋转接触容差，默认 1/1024 格，范围 0.00001～1/256 格；只控制轴承与静态世界方块，不改变 Sable 原生物理碰撞体或其他运动类型。
- 服务端：碰撞诊断记录开关，默认开启。关闭后 `/spc cart_status` 和 `/spc bearing_status` 明确提示关闭，碰撞检测继续执行。
- CLIENT 配置保存于实例 `config/sable_physical_contraptions-client.toml`；SERVER 配置保存于存档 `serverconfig/sable_physical_contraptions-server.toml`。NeoForge 负责服务器配置的连接同步。
- 单人世界内可编辑当前存档 SERVER 配置；多人远程服务器及已开放局域网的世界遵守 NeoForge 原生权限限制，客户端不能通过此页更改服务器规则。独立服务器由管理员编辑对应文件。
- 不提供解除物理组装器安全保护的开关。

## 多语言范围

随 Minecraft 语言设置切换简体中文、繁体中文、英语、日语。四种语言覆盖 HUD、装配错误、保护提示、配置名称/说明、诊断命令常规错误提示和客户端计时命令提示。其他语言使用 Minecraft 的英语回退。

详细开发诊断正文（逐方块坐标、预算/恢复阶段、拆卸检查等）仍保留现有中文格式，尚未全量结构化为可翻译组件；不能据此宣称所有开发输出都已四语化。

## 当时的剩余风险与后续优先级

> 历史说明：下列第 1～3 项已在 0.7.1 中加入对应实现，验证范围见 [0.7.1 审查](REVIEW-0.7.1.md)。当前验收状态以 [验证与已知限制](../VALIDATION.md) 为准。

1. **嵌套矿车快照恢复异常的完整事务回滚**：PackedStructures.restore 在恢复子实体之前清空根快照，异常清理以当前物理体为范围。第三方方块实体加载或子结构加入世界失败时，整个家族的原子回滚仍不完整。应单独实现家族级事务与故障注入验证，避免在无游戏环境下仓促改写库存恢复链路。这是实际代码风险，不是已复现的用户数据丢失报告。
2. **矿车转弯旋转扫掠**：现有矿车路径以固定朝向平移扫掠为主，尚未覆盖一 tick 内车身同时平移与转向的完整旋转体积。不能把高速直线测试通过理解为转弯无穿透。
3. **停转原因细分**：预算不足、未加载区块目前仍可能在普通 HUD 中呈现碰撞停转；详细诊断能区分部分来源。建议将原因作为独立状态码同步，并提供可选碰撞方块高亮。
4. **可选模组与真实多人验证**：补齐 Simulated 二进制版本矩阵，以及不同客户端语言、进出维度、重连、跨区块保存重载的实机检查。
5. **性能结论限制**：本轮证明减少了重复计算/分配，不声称提高了具体 FPS/TPS 百分比；需要相同世界及相同结构的基准数据。
