# 0.7.1-alpha 审查记录

本版按要求仅递增第三位。范围为上一版提出的三项改进，以及进度触发路径核对。未启动 Minecraft、服务器、GameTest 或桌面控制。

## 嵌套恢复事务

PackedStructures 使用线程内共享事务覆盖整个恢复家族；物品放置入口将提交边界延长到根实体加入成功之后。加载 NBT、子实体挂载、子实体加入或根实体加入失败时，逆序清理已登记资源。清理某个资源失败会记录为原异常的 suppressed exception，并继续清理其余资源。物理约束、强制加载票据、物理体、子实体及父级映射分别释放；actor 停止回写被跳过，避免回滚时重复处理物品。

只在全部恢复成功后清空临时快照。物品中的原快照不原地修改，Create 正常物品扣除位于放置调用成功之后。本实现不增加整个大型 NBT 的重复复制，也不改成分 tick 库存加载。

保护范围是同步恢复的 RuntimeException/加入拒绝；不声称提供进程崩溃或断电事务。第三方清理代码若自身抛错，无法保证该第三方资源一定释放。Create 在恢复前创建的空承载矿车可能留在现场，失败快照仍在原物品中。

## 矿车转弯

CartTurning 在承载矿车 tick 前保存姿态，在 Create 更新朝向之后、工作部件运行之前执行组合扫掠。碰撞形状来自真实方块形状，排除虚拟矿车锚点和同家族物理体。转弯检测使用 getAnchorVec 的锚点偏移，与 toGlobalVector/物理目标一致。

RigidSweep 沿最短四元数旋转和线性平移递归精检；包络负责筛选，不能直接作为碰撞结论。旋转轴投影不变性用于排除相切墙面，纯平移继续走原精确平移路径。预算用尽安全停转并明确显示原因。结构子体沿父级路径检测，仍沿用稳定子结构的朝向规则。

转弯受阻后恢复捕获的承载/耦合车位置及根结构角度、停止速度并重新定位物理目标，后续 tick 重试。成功的角度重试不能覆盖本 tick 的平移阻挡。被拒绝的转向不会触发“转弯时暂停工作”，钻头仍可处理符合现有朝向限制的阻挡物。

此检查覆盖一个 tick 起终姿态之间的插值路径；不能据此保证任意第三方瞬移、耦合车 tick 顺序或客户端插值均无问题。耦合车和嵌套稳定子结构需要实际游戏回归。

## HUD 与配置

新增未加载区块、检测预算不足、世界边界、结构数据不可用四种原因。CollisionState 与可关闭的开发诊断缓存分离；客户端不执行碰撞扫描。服务端实体元数据同步状态码与可选阻挡坐标，只在变化时同步。

戴工程师护目镜、看向受阻的本 Mod 结构方块时，使用 Create Outliner 绘制红色阻挡轮廓。Mods → Sable Physical Contraptions → 配置 → 客户端可关闭高亮。开关默认开启；关闭整个 HUD 同时关闭高亮。离开目标后由原生 Outliner 淡出。

障碍使用其碰撞形状包围框，因此墙等 1.5 格形状会如实显示。其他物理体上的障碍先转成渲染世界坐标，其轮廓为世界轴对齐包围框，用于定位方块，并非最终精检 OBB。目标区块未在客户端加载时不画框。

常规 UI 四种语言条目保持一致；详细开发诊断正文仍为中文。本版不改变已有 1/1024 轴承静态世界容差。

## 进度兼容性

没有全局禁用或清除进度的逻辑。转换入口替换 Contraption 的方块迁移，并未取消外层控制方块的整个 assemble 流程。已核对本地 Create 源码和发布二进制中的奖励调用：

- MechanicalBearingBlockEntity：WINDMILL、WINDMILL_MAXED、CONTRAPTION_ACTORS。
- ClockworkBearingBlockEntity：CLOCKWORK_BEARING、CONTRAPTION_ACTORS。
- PulleyBlockEntity、ElevatorPulleyBlockEntity、MechanicalPistonBlockEntity 等：原有装配奖励调用保留。
- AbstractContraptionEntity 座位乘坐/下车的 LONG_TRAVEL 路径没有被替换。
- 普通火车仍不在物理化筛选范围内。

因此不应把本 Mod 理解为“安装后不能获得进度”。但也不能保证所有原版/Create/第三方进度均已验证：某些条件读取方块实体实际坐标，而物理体方块位于 Sable plot；依赖位置、生物群系或自动化操作者身份的条件需要单独核对。机械自动破坏/放置本来就不一定等于玩家亲自操作。测试仅确认关键调用与注入契约，并非实际授予进度的游戏测试。

## 验证

测试覆盖家族回滚故障注入、提交失败、清理异常继续处理；纯平移/转弯中途障碍/初始倾斜/旋转轴相切/沿轴平移/正反路径；已发布依赖上的注入描述符与调用顺序；原生装配奖励入口保留；四语言键和占位符一致性。

依赖矩阵：Sable 2.0.3 + Create 6.0.10 Maven、6.0.10 release、6.0.11，以及 Sable 2.0.5 + Create 6.0.11。构建产物为 build/libs/sable-physical-contraptions-0.7.1-alpha.jar。
