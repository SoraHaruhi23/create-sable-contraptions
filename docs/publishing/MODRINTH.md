# Create: Sable Contraptions

## English

**Bring Create contraptions into Sable physics.**

Supports elevators, mechanical/windmill/clockwork bearings, rope pulleys, mechanical pistons, gantries, minecart contraptions, and stabilized children. Retains Create controls and movement behaviors, with collision stopping, editing while moving, inventory/fluid access, and portable interface docking. Regular Create trains are not converted.

Engineer's goggles display structure status and stop reasons. Options are available through the Mods configuration screen. UI languages: Simplified Chinese, Traditional Chinese, English, and Japanese.

**Requirements:** Minecraft 1.21.1, Java 21, NeoForge 21.1.228+, Create 6.0.10+, and Sable 2.0.3+.

**Current version: 0.7.6-beta.** Place the regular JAR in mods and use matching client/server versions. Back up worlds before upgrading; data from the former mod ID requires migration through 0.7.3-alpha. Beta release: compatibility with third-party components and complex structures needs further testing.

## 中文

**让 Create 动态结构接入 Sable 物理系统。**

支持电梯、三类轴承、绳索滑轮、动力活塞、龙门、矿车及稳定子结构。保留 Create 控制与移动工作行为，支持碰撞停转、运行中编辑、库存与流体交互、便携式接口对接。普通 Create 列车不进行物理化。

工程师护目镜显示结构状态与停转原因。通过 Mods 配置页调整选项；界面支持简中、繁中、英语、日语。

**前置：** Minecraft 1.21.1、Java 21、NeoForge 21.1.228+、Create 6.0.10+、Sable 2.0.3+。

**当前版本：0.7.6-beta。** 将普通 JAR 放入 mods，客户端与服务端保持版本一致。升级前备份存档；旧名称版本的数据须先通过 0.7.3-alpha 转换。Beta 阶段，第三方组件和复杂结构的兼容性仍需测试。
