# 首个 Beta 发布前检查

日期：2026-10-03。版本：0.7.6-beta。用户同意由 alpha 进入 beta；本轮不启动 Minecraft、独立服务器、GameTest 或桌面控制，也不创建远程仓库。

## 代码复核

重点检查数据与生命周期、碰撞及工作部件保护、近期储罐与接口修复、客户端隔离和配置入口，并以现有几何与字节码契约检查覆盖其余集成入口。这是发布前静态复核及自动检查，不是对所有游戏状态的正确性证明。

- PhysicalStorage：库存/流体视图查询真实物理方块能力，持久化不另写一套动态结构库存；PhysicalActorTickerMixin 放行真实储罐 tick，使连接重建、能力刷新与延迟同步继续运行。
- PortableAnimation：移动端读取固定接口实际伸出距离，不再把传输超时误认为断开。普通与 Flywheel 渲染使用同一 actor 动画数据。
- PackedStructures / RestoreTransaction：矿车快照读取真实方块实体；家族恢复先登记逆序清理、整体成功后提交。保留清理失败、空承载矿车残留及非崩溃原子事务等已知边界。
- ElevatorPhysics / CartLifecycle：检查物理约束、加载票据及矿车移除清理入口；生命周期契约由测试覆盖，不据此声称长期资源泄漏测试完成。
- 碰撞及钻头：检查现有静态/运动扫掠、预算停转、子结构传播测试及 AssemblySourceProtection 家族/控制器/装配站保护。未更改算法与容差。
- ElevatorLink：只选择受支持机构与显式归属的稳定子结构，普通列车不转换。
- 客户端：配置入口使用 Dist.CLIENT；客户端 Mixin 单独注册，公共侧未登记 client.* Mixin。
- 旧名称：运行源码没有迁移读取，旧 ID 仅在不兼容依赖声明中保留以阻止同时安装；没有删除用户存档或配置。

未发现本轮需要新增修复的确定性发布阻断问题。修正 README 拆卸范围描述：电梯要求目标为空，不能把其他机构的替换策略泛化到电梯。
