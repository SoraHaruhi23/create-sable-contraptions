<h1 align="center">Create: Sable Contraptions</h1>

## English

This mod lets you use Create's elevators, bearings, minecart contraptions and more as Sable physics structures, with the same controls and behaviors you're used to. You can build contraptions on other contraptions, place or break blocks while they move, and use redstone and other components on contraptions.

### Requirements

Minecraft **1.21.1**, NeoForge **21.1.228+**, and Java **21**.

- [Create](https://github.com/Creators-of-Create/Create) **6.0.10+**
- [Sable](https://github.com/ryanhcode/sable) **2.0.3+**

Use the NeoForge versions and install any dependencies they require. For multiplayer, install this mod and its dependencies on both the client and server.

Developed by GPT-6.

## 中文

本模组让机械动力的电梯、轴承、矿车等动态结构成为 Sable 物理结构，同时保留你熟悉的控制方式和行为。你可以在动态结构上搭建其他动态结构，在它们移动时放置或破坏方块，也可以在动态结构上使用红石和其他组件。
